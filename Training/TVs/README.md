# Digital Signage

 

## To Start signage

1. Turn On TV(s)
2. ≡ → Ambient



## To Edit signage

#### On Phone

1. Open Amazon Photos
2. \+ → Manually upload photos
3. Select the photo of the menu you saved from Cat's Message
   * it will upload
4. (optional) add the menu photo to the Menu album
   1. open the photo
   2. pull up on the bottom bar
   3. slide the, now top, bar to the left until you see the "Add to album" button
   4. Add to album → "Menu"
5. continue on TVs

 

#### On TVs

1. Turn On TV(s)
2. ≡ → ⛭
3. Display \& Sound
4. Ambient Experience
5. Ambient Preferences
6. Change Background
7. → My Photos
